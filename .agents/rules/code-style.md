# Coding Rules & Guidelines

When generating or modifying code for DevForge, the AI Agent must follow these rules:

1. **TypeScript First**: Always use strict TypeScript. Define interfaces for all component props and data models.
2. **Tailwind CSS**: Use Tailwind CSS for all styling. Avoid custom CSS files unless absolutely necessary.
3. **Component Structure**: Keep React components small and modular. Use functional components and hooks.
4. **Beginner Friendly**: Because this is an open-source project for beginners, always write highly descriptive comments explaining complex logic so contributors can learn by reading the code.
